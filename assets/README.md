# Brand asset

`mascot.jpg` is the owner's existing avatar, identical to `Downloads/revive360/avatar-revive360-quadrado.jpg` (SHA-256 `f9cea4aaf9c583977948f51402301d702713764b98a215416dadb2c0bcf922c3`). It is reused for the local preview. `mascot-small.jpg` is a 64×64 reduction, `mascot-muted.jpg` its muted variant, and `mascot-medal.jpg` a 512×512 reduction, derived from that exact source. SVGs embed these thumbnails directly and need no external requests. Brand art is not relicensed by this repository's MIT code license; no new mascot was generated.

`fonts/DroidSans-Bold.ttf` is bundled from Fedora's `google-droid-sans-fonts` package for consistent PNG rendering without system font lookup. Its Apache 2.0 license and Android Open Source Project copyright are preserved in [fonts/NOTICE](fonts/NOTICE). Only this font is loaded by the pinned `resvg-py` renderer. SVG text uses Droid Sans with browser fallbacks. Compact PNGs render at 2× (72 px high); the Project medal PNG is 1024×1024 with transparent corners.
